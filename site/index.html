Make YouTube™ great again

The small things YouTube™ is missing: audio-only mode, cinema mode, looping, screenshots, comment drafts, a floating video & more. Switch each feature on or off, keep only what you use.

Firefox

Install from Firefox Add-ons: one click, updates automatically.

Add to Firefox

Without the store

A package signed by Mozilla for installing straight from GitHub. It works in any Firefox and keeps updating on its own.

  1. Download myga-firefox.xpi in Firefox
  2. Confirm the install prompt (or drag the file onto a Firefox window)
Unsigned build (Developer Edition, Nightly)

Regular Firefox only installs signed add-ons. Firefox Developer Edition, Nightly & ESR can install the unsigned build:

  1. Open about:config and set xpinstall.signatures.required to false
  2. Download myga-firefox.zip
  3. Open about:addons, click ⚙ → Install Add-on From File… and pick the zip

To just try it in any Firefox: about:debugging → This Firefox → Load Temporary Add-on… (removed when Firefox restarts).

Chrome, Edge, Opera & Vivaldi

Install from the Chrome Web Store, or Microsoft Edge Add-ons in Edge: one click, updates automatically. Opera & Vivaldi install from the Chrome Web Store.

Add to Chrome Add to Edge

Without the store

  1. Download myga-chrome.zip and unzip it
  2. Open chrome://extensions (Edge: edge://extensions, Opera: opera://extensions)
  3. Switch on Developer mode
  4. Click Load unpacked and pick the unzipped folder

Manually installed extensions don't update on their own: repeat these steps with a newer release to update.

From source

Build it yourself from the open source code, with Node.js 24:

  1. git clone https://github.com/TautvydasDerzinskas/make-youtube-great-again.git
  2. npm ci & npm run build
  3. Load dist/chrome or dist/firefox as above
Development guide

Features

Every feature can be switched on or off from the extension's popup.

Audio mode

Listening to music, a podcast or a talk? Mark a video as audio and it plays at the lowest video quality behind its artwork: less data, same sound quality. Remembered for every marked video, and a whole playlist can be marked in one click.

Cinema mode

Fade out everything around the video with one click. Press Esc or click around the video to bring the page back.

Screenshots

Save the current frame in one click, in the quality you're watching. Download or delete them under the video or in the popup, or jump back to the moment each was taken.

Comment drafts

Not ready to post yet? Save your comment as a draft. Drafts show above the comments, ready to publish, edit or delete, and all of them are listed in the popup.

Channel blacklist

Hide videos of channels you don't want to see, everywhere: home feed, search, the sidebar, playlists. Blacklist a channel with the Blacklist button under a video, or while hovering any video in a list. Remove channels from the list in the popup.

Floating video

Keep watching while you scroll down to read the comments: the video follows you in a small window you can move anywhere and resize.

Loop

Play a video on repeat with one click.

Custom progress bar

Swap the progress bar for a playful one: Nyan Cat, a unicorn, a panda and more.

Hide comments

Hide comments and live chat messages when you'd rather not see them.

Hide the Thanks button

Remove the "Thanks" button from under videos.

History

See the videos you've recently watched and looped.

Pick your progress bar

Live previews, drawn by the extension's own styles. Pick one in the popup: Custom progress bar → ⚙.

FAQ

Is it free?

Yes. It's free and open source under the MIT license, with no ads and no paid features.

Does it collect my data?

No. Everything it saves stays in your browser, and it has no accounts, analytics or tracking. See the privacy policy.

Why this name?

Only because it sounds funny. There's no political message.

Found a bug or have an idea?

Open an issue on GitHub, contributions are welcome too.

Private by design

Everything the extension saves (settings, marked videos, drafts, screenshots, history) stays in your browser. No accounts, no analytics, no tracking. Privacy policy
